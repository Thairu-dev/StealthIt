# Notes on what is deliberately NOT here:
#
#   google-generativeai / anthropic / openai / cerebras_cloud_sdk
#     All five providers are called over plain HTTPS via urllib. The official
#     SDKs would add ~60 MB (grpc, protobuf, httpx, pydantic) to the packaged
#     binary, reconfigure global state per call, and in the Gemini SDK's case
#     expose a streaming iterator that cannot be cancelled mid-response.
#
#   python-dotenv
#     API keys live in DPAPI-encrypted storage, not a plaintext .env.
#
#   qtawesome
#     Pulled in ~2 MB of icon fonts and rasterised PNGs to disk on every
#     startup. Icons here are drawn with QPainter or are plain text.
#
#   markdown
#     Replaced by a purpose-built streaming renderer that keeps partial code
#     fences styled and escapes model output safely.
